## 训练与复现

```powershell
# 阶段 2：NEU train+val 重划分上微调（120 epochs）
python scripts/finetune_neu.py --init runs/severstal_bin/weights/best.pt `
    --name n640_plus_sev_std --data data/neu_det_plus/data.yaml --epochs 120 --lr0 0.01

python scripts/evaluate.py --weights runs/n640_plus_sev_std/weights/best.pt `
    --imgsz 640 --out runs/eval_n640_plus_sev_std.json
```

## 关键说明（诚实边界）

- Severstal 只有 4 类缺陷（二分类预训练使用），与 NEU-DET 六类**不等价**；因此**不能**把 Severstal 的 mAP 当成“六类跨厂准确率”。
- 新模型在 NEU-DET 独立测试集上优于基线（mAP50 +1.66 个百分点、漏检率下降），但没有真实工厂六类标注的跨厂测试集；跨厂泛化仍需要 X-SDD 或产线实拍标注验证。
- 推荐业务阈值：conf≈0.25~0.35；追求低漏检可降至 0.10~0.15 并人工复核。
- 数据为公开数据集（NEU-DET 学术用途；Severstal 来自 Kaggle 竞赛并由 ModelScope 镜像，遵守原数据集/竞赛条款）。

## 引用与框架

- NEU-DET：K. Song, Y. Yan, Applied Surface Science 285 (2013) 858-864；Y. He et al., IEEE TIM 69(4) (2020) 1493-1504。
- Severstal：Kaggle `severstal-steel-defect-detection`；ModelScope `Voxel51/severstal_steel_defects`。
- 框架：ultralytics（AGPL-3.0）；比赛演示用途，商业化部署需评估授权。

## 数据扩充实验（2026-11-03，未采用）

- 新增公开数据 GC10-DET：2312 张、2294 个 XML、清洗后 10 类、3563 框；1837 train / 455 val。
- 训练流程：GC10 10 类预训练 40 轮 → NEU 六类 1380/150 微调 120 轮。
- 候选测试集：mAP50 0.8023、mAP50-95 0.4594、P 0.7225、R 0.7795，**低于当前线上 0.8223**。
- 结论：类别体系与 NEU 六类不一致，辅助数据未带来提升；**不替换模型，保留当前跨厂泛化版**。实验脚本/权重保留在 `runs/n640_gc10_plus/` 与 `scripts/`。
