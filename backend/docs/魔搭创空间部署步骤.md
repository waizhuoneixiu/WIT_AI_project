> ✅ **已于 2026-10-30 部署成功**：https://modelscope.cn/studios/waizhuoneixiu/steelscan-demo 
> 部署细节见 docs/魔搭部署记录.md。

> 目标：把 `deploy/modelscope_package` 变成一个公网链接，用于比赛“智能体链接”和演示。

## ⚠️ 先分清两个东西

| 东西 | 用途 | 适合 |
| --- | --- | --- |
| **我的 Notebook**（你现在页面上的） | 临时开发机，有免费 CPU/GPU 实例，会停机/限额 | 跑代码、调试，**不适合当比赛链接** |
| **创空间（Studio）** | 长期在线的公网网页，上传代码后自动构建 | ✅ 比赛演示/智能体链接 |

我们要用 **创空间**。

---

## 方案 A：我给你令牌，我代你推送（最省事，推荐）

### 你只需要做 2 件事

1. **创建创空间**
   - 打开 https://modelscope.cn/ → 顶部导航「**创空间**」→「**创建创空间**」
   - 名称：`steelscan-demo`（可改）
   - SDK 类型：**Gradio**
   - 可见性：**公开**
   - 硬件：**CPU 免费实例**
   - 点「创建」
2. **生成访问令牌**
   - 右上角头像 →「**账号设置**」→「**访问令牌**」→「**新建访问令牌**」
   - 复制生成的令牌（只显示一次）
   - 把 **创空间 Git 地址**（创建后空间页「Git」里可复制，形如 `https://www.modelscope.cn/studios/waizhuoneixiu/steelscan-demo.git`）+ **令牌** 发我

### 我拿到后做什么

- 把 `deploy/modelscope_package` 推送到你的空间；
- 触发构建、查看日志、修错误；
- 构建完成后把公网链接发你，并帮你验证页面和推理。

> 令牌只用于这次推送，我不会写进任何代码/仓库；推送完你可以随时在账号设置里删除它。

---

## 方案 B：你自己网页上传（不用给我令牌）

1. 按方案 A 第 1 步创建创空间；
2. 进入空间 →「**文件**」→ 上传部署包里的**全部文件**（保持目录结构）：
   - 根目录：`app.py`、`inference_onnx.py`、`contract.py`、`requirements.txt`、`README_部署说明.md`
   - `models/` 目录：`best.onnx`
   - `samples/` 目录：12 张样例图
3. 等 2~5 分钟构建完成；
4. 打开空间链接，上传/点样例图测试；
5. 把链接发我，我帮你验收。

如果网页上传不方便，用 Git：
```bash
git clone https://www.modelscope.cn/studios/waizhuoneixiu/steelscan-demo.git
# 把部署包内全部文件复制到 clone 下来的目录
git add .
git commit -m "SteelScan demo"
git push
```
（第一次 push 会要求输入用户名 + 访问令牌）

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 页面 404 / 构建中 | 等 2~5 分钟，看「构建日志」 |
| 构建失败缺少 onnxruntime | 确认 `requirements.txt` 上传了且未被改 |
| 上传图片无结果 | 先用 `samples/` 里的图测试 |
| 想换自己的模型 | 替换 `models/best.onnx` 后重新 push |
