## 4. 如何调用（给队友/智能体）

浏览器直接打开演示链接即可；程序调用示例：

```python
import requests
BASE = 'https://studio-waizhuoneixiu-steelscan-demo.api-inference.modelscope.net'
TOKEN = '你的魔搭访问令牌'   # 只放在后端环境变量，不要写进前端
H = {'Authorization': 'Bearer ' + TOKEN}

# 1) 上传图片
with open('test.jpg', 'rb') as f:
    r = requests.post(BASE + '/gradio_api/upload',
                      files={'files': ('test.jpg', f, 'image/jpeg')}, headers=H, timeout=60)
path = r.json()[0]
# 2) 调用检测
r = requests.post(BASE + '/gradio_api/call/detect_ui',
                  json={'data': [{'path': path, 'meta': {'_type': 'gradio.FileData'}}, 0.25]},
                  headers=H, timeout=60)
event_id = r.json()['event_id']
# 3) 取结果（SSE）
r = requests.get(BASE + '/gradio_api/call/detect_ui/' + event_id, headers=H, timeout=60)
print(r.text)
```
