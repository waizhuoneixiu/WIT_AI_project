# 给队友的交付清单（backend）

> 用途：把后端和接口交给队员二（App）、队员三（材料/验收）。  
> 原则：**只给联调 Key，不给 DeepSeek Key；不传 `.env`；仓库保持私有。**

---

| 方式 | 给什么 | 适合 |

## 1. 给队员二（App 开发）——接口联调包

### 1.1 需要给的东西

1. **服务地址**（二选一）：
   - 同一 Wi-Fi（最简单）：电脑上 `ipconfig` 查 IPv4，例如 `http://192.168.1.20:8000`；手机/电脑同一网段即可。
   - 远程：cpolar / ngrok 穿透后的 `https://xxx.cpolar.cn`（步骤见 `docs/内网穿透联调步骤.md`）。
2. **临时 API Key**（不要给 DeepSeek Key！）：启动时自己设一个，例如：
   ```powershell
   $env:STEELSCAN_API_KEY="steel-ai-demo-2026"
   python server.py --port 8000
   ```
   把这个 `steel-ai-demo-2026` 私聊发给队员二即可；演示完可换掉。
3. **文档**：
   - `docs/队友API调用文档.md`（必看：地址、鉴权、示例代码、错误码）
   - `docs/API接口文档.md`（完整字段）
   - `docs/openapi.json`（导入 Postman / 自动生成客户端）
   - `docs/接口调用示例.py`（可直接运行）
4. **契约要点**（口头也要强调）：
   - 类别 class_id：`0 龟裂、1 夹杂、2 斑块、3 麻点、4 轧入氧化皮、5 划痕`；
   - `bbox_xyxy` 是**原图像素坐标**（左上原点），按原图尺寸等比缩放画框；
   - 检测完成 ≠ 人工确认，复核状态单独字段；
   - 任务状态 `queued / running / completed / failed`；复核 `pending / confirmed / corrected / unresolved`；
   - 错误码：401（Key 错）、400（图片坏）、409（复核版本冲突）、422（参数错）、404（记录不存在）。

### 1.3 手机联调注意事项

- 手机与电脑连**同一个 Wi-Fi**（不要连访客网络/热点隔离）；
- Windows 防火墙放行 8000 端口（管理员 PowerShell）：
  ```powershell
  netsh advfirewall firewall add rule name="SteelScan API 8000" dir=in action=allow protocol=TCP localport=8000
  ```
- Android 9+ 默认禁止明文 HTTP：App 里需配置 `android:usesCleartextTraffic="true"` 或 network-security-config（或让后端走 HTTPS 穿透地址）。

## 3. 队友自己跑后端（可选）

```powershell
conda activate AIvision
cd backend
pip install -r requirements.txt
$env:STEELSCAN_API_KEY="steel-ai-demo-2026"

# 自检
```

## 4. 千万不要给/不要提交

1. **DeepSeek API Key**（`sk-...`）：只放后端 `.env`，队友不需要，不要发群/进材料；
2. `.env` 文件、`storage/` 数据库、`reports/` 原始日志；
3. 3.39GB 本地大模型目录（`models/DeepSeek-R1-Distill-Qwen-1.5B`）；
4. 公开仓库/公开链接里的真实密钥、私人联系方式；
5. 如果 Key 已经公开过：去平台删除重建，再更新 `.env`。
