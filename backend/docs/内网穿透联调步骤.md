# 内网穿透联调步骤（cpolar / ngrok）

> 场景：后端跑在你本机 `127.0.0.1:8000`，队友/前端在外网访问不到，用内网穿透临时映射成公网 HTTPS 地址。
> 约定：**先设置 API Key 再开穿透**，避免接口裸奔。

---

## 0. 启动带鉴权的后端（先做这一步）

```powershell
conda activate AIvision
cd "D:\Users\何ch\source\repos  AI\AIvision1"
$env:STEELSCAN_API_KEY = "换成一个随机字符串，例如 steel-ai-2026-abc123"
python server.py --port 8000
```

本地验证：

```powershell
curl.exe http://127.0.0.1:8000/health
curl.exe -H "X-API-Key: steel-ai-2026-abc123" -F "image=@data/neu_det/images/test/patches_110.jpg" http://127.0.0.1:8000/detect
```

把 **公网地址 + API Key** 私聊发给队友（不要发群/公开文档）。

---

## 方案 A：cpolar（国内访问较稳，免费版够联调）

1. 注册：https://www.cpolar.com/ （免费注册）。
2. 下载 Windows 客户端并安装（官网「下载」→ Windows 64 位）。
3. 登录后台 →「验证」页面复制 **Authtoken**；命令行执行一次：
   ```powershell
   cpolar authtoken 你的AUTHTOKEN
   ```
4. 启动隧道：
   ```powershell
   cpolar http 8000
   ```
5. 看输出里的 `Forwarding` 一行，得到公网地址，例如：
   `https://xxxx-xx-xx.cpolar.cn`（免费版地址随机、隧道关闭即失效，重开可能变）。
6. 验证：
   ```powershell
   curl.exe https://xxxx.cpolar.cn/health
   ```
7. 把 `https://xxxx.cpolar.cn` + Key 发给队友。

> 免费版限制：隧道 24 小时内可能过期、带宽有限、地址每次重启会变；联调够用，正式演示建议提前重开并更新地址。

---

## 方案 B：ngrok（海外线路，偶尔慢/被墙，能用则快）

1. 注册：https://dashboard.ngrok.com/signup （免费账号）。
2. 安装（二选一）：
   - 官网下载 Windows 版 `ngrok.exe`，放到任意目录；
   - 或 `winget install ngrok.ngrok`。
3. 后台「Your Authtoken」复制 token，执行一次：
   ```powershell
   ngrok config add-authtoken 你的NGROK_TOKEN
   ```
4. 启动隧道：
   ```powershell
   ngrok http 8000
   ```
5. 得到 `Forwarding https://xxxx.ngrok-free.app -> http://localhost:8000`。
6. 验证：
   ```powershell
   curl.exe https://xxxx.ngrok-free.app/health
   ```
7. 把地址 + Key 发给队友。
   - 注意：免费版首次访问可能需要浏览器点一次「Visit Site」，或请求头加 `ngrok-skip-browser-warning: 1`。

> 国内网络访问 ngrok 可能不稳定；如果队友打不开，改用 cpolar / 花生壳 / 云服务器。

---

## 方案 C：其他（备选）

- **花生壳**：注册 → 新建内网穿透映射（HTTP，内网主机 127.0.0.1:8000）→ 获得外网地址；免费版有流量/带宽限制。
- **cloudflared**：`cloudflared tunnel --url http://localhost:8000`（免费临时 https 地址，需能访问 Cloudflare）。
- **SSH 反向隧道**（有公网服务器时）：
  ```bash
  ssh -R 8000:127.0.0.1:8000 user@你的公网服务器
  ```
  服务器上访问 `http://127.0.0.1:8000`，再用服务器 Nginx 反代成 HTTPS。
- **frp**：自建 frps/frpc，适合长期稳定演示（需要公网服务器）。

---

## 安全与注意事项

1. **必须启用 API Key**（`STEELSCAN_API_KEY`），否则公网任何人可调用你的接口。
2. Key 只私聊给队友；不要在 PPT/视频/公开仓库出现；联调结束可换 Key。
3. 联调结束**关闭隧道**（Ctrl+C）并在下次使用时重开、更新地址。
4. 本机防火墙若拦截，Windows 会弹窗询问「是否允许 Python 访问网络」→ 勾选专用网络允许。
5. 免费穿透带宽低，不要上传大图/视频或高频压测。
6. 队友若在浏览器前端直接调用，注意 HTTPS 页面不能调 HTTP 地址（混合内容）；cpolar/ngrok 给的是 HTTPS，无需担心。
7. 正式比赛演示优先用云服务器或魔搭创空间，穿透只作临时联调。

## 队友拿到地址后的验证命令

```powershell
# 健康检查
curl.exe https://你的穿透域名/health

# 带 Key 检测
curl.exe -X POST "https://你的穿透域名/detect" -H "X-API-Key: 你的KEY" -F "image=@本地图片.jpg"
```

成功返回含 `defect_count` / `defects` 即联调打通。
