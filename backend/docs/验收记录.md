## 3. 大模型实测说明

- 本地模型：`models/DeepSeek-R1-Distill-Qwen-1.5B`（ModelScope，3.39GB）
  - GPU 加载约 8s（显存约 3.5GB），单次分析约 16~22s，问答约 10~20s；
  - 该模型会先输出"思考过程"再输出 JSON，代码已做**思考段剥离 + 精简提示词重试**，保证 JSON 五字段可解析；
  - 质量：能给出缺陷事实、参考原因、复检步骤，但分析深度与措辞明显弱于云端新模型，适合作为**离线兜底/隐私场景**。
- DeepSeek 云 API：代码已适配（OpenAI 兼容，`response_format=json_object`，超时重试、失败降级），**真实调用仍待 API Key**（本机无 Key，未做云端真实调用）。
- 选择逻辑：`LLM_PROVIDER=auto` → 有 `DEEPSEEK_API_KEY` 用云 API，否则本地模型存在用本地，否则规则模板；返回 `source` 标明来源。
