# 交付包使用说明

本文件夹里有**两个独立的压缩包**，直接拖进微信/QQ/钉钉发给对应队友即可：

| 发给谁 | 压缩包 | 里面是什么 |
| --- | --- | --- |
| 队员二（App 开发） | `给队员二_App联调包.zip` | 接口文档、速查卡、真实响应样例、30 秒自测脚本、现成消息文案 |
| 队员三（材料/PPT） | `给队员三_材料包.zip` | 指标速查、模型卡、训练记录、验收记录、图表、消息文案 |

## 发送步骤

1. 打开文件夹，**拖拽对应 zip 到聊天窗口**发送；
2. 再复制 zip 里的 `给队友X的消息.txt` 内容发过去（把地址/Key 占位符替换成真实值）；
3. 对队员二：确认他跑通 `06_测试连接.py`（看到"全部连通 ✔"）；
4. 对队员三：把魔搭创空间演示链接补发给他（部署完成后）。

## 安全提醒

- 两个包都**不含**真实密钥、`.env`、数据库、3.39GB 本地大模型；
- 给队员二的临时 API Key 建议单独发，不要写进群公告；
- DeepSeek Key 只留在队长电脑的后端 `.env`，不要发给任何队友；
- 演示结束后更换临时 API Key。

## 可选：GitHub 方式

如果队友能上 GitHub：把他们账号加到 `WIT_AI_project` 私有仓库（Settings → Collaborators），代码看 `backend/`，README 里有完整启动说明。
