## 3. 模型与价值验证

保留已有 YOLO26n 模型卡、训练划分和指标来源；本轮不重新训练、不改变阈值来追赶目标。离线推理基准、魔搭服务器 inference_ms、包含上传/排队/网络的业务总耗时、Android等待时间分别记录，不能互相替代。

大模型价值仍需通过同一批证据的“检测+固定模板”与“检测+大模型/知识”对照测量时间、修订量、事实/引用和成本；约30%改善是待验证目标，不预设结论。未审核知识不能声称行业标准。
