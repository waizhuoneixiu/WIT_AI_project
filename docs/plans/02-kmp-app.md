## 一、你负责把什么做出来

交付一款可安装、可操作、可连接真实后端的Android应用。用户可以选图或拍照、输入批次信息、查看YOLO结果、向助手追问、人工确认并查看历史和报告。KMP用于共享业务与界面组织，其他平台在核心流程完成后再评估。

你主要负责前端与交互，不承担YOLO训练、大模型供应商接入和真实统计计算。先用合成数据完成页面，后接入队员一的接口；与队员三共同检查文案、报告和演示流程。

## 二、页面与操作任务

| 页面 | 首轮必须完成 | 重点状态 |
|---|---|---|
| 检测 | 拍照/选图、批次号、可选工件号、提交按钮 | 未选图、权限拒绝、上传中、失败重试 |
| 结果详情 | 原图/框图、缺陷卡片、类别/分数、复核按钮 | 检测中、未检出、待复核、已确认、无法判断 |
| 助手 | 当前检测上下文、文字提问、回答、引用与复检清单 | 生成中、超时、中断、证据不足 |
| 记录与批次 | 列表、筛选、详情、真实统计、报告入口 | 空记录、加载失败、缓存数据 |
| 我的与设置 | 后端连接、版本、上传说明 | 可用、断线、配置错误 |

主导航采用“检测、记录、助手、我的”。浅灰背景、深色文字和蓝色主要按钮；待复核用橙色，已确认异常用红色，同时提供文字与图标，不能只靠颜色。

结果页优先显示原图和下一步动作。缺陷卡片与框可以互相定位；报告明确区分AI草稿和人工确认状态。模型参数和服务细节放到必要的版本/设置区域。

## 三、按顺序完成的实现任务

### 1. 工程与合成页面

- 采用Kotlin Multiplatform与Compose Multiplatform组织应用；Android先可运行，再考虑桌面。
- 确认最低可用设备和Android构建环境，记录实际版本。优先参考官方项目与示例，登记复用来源。
- 按共同类别映射和接口字段建立数据模型，准备正常响应、空检出、超时与失败的合成页面。
- 合成模式与真实服务模式有明确标记，最终实录使用真实接口时关闭合成数据来源。

### 2. 图片输入与缺陷绘制

- 实现拍照、系统选图、权限拒绝后的说明和重新选择。避免重复点击产生重复任务。
- 提交前保留批次号与图片信息，按约定处理大小和方向；不把低清晰度图片通过放大伪装为高精度采集。
- 以返回的原图尺寸和bbox_xyxy绘框。处理等比缩放、留白、旋转及横竖屏后坐标，保证框与原图同步。
- 列出多个缺陷、分数与人工状态；可放大查看。模型空结果展示“未检出六类目标缺陷”，不是绿色“合格”。

### 3. HTTP、WebSocket与状态恢复

- 通过后端统一上传和查询，不从App直接调用大模型供应商，不内置云端Key。
- 上传后保存inspection_id、task_id，根据WebSocket事件更新进度与回答。
- 使用event_id避免重复消息重复追加；切换页面、应用回到前台或断线后重新查询状态。
- 检测完成与分析完成分别显示。大模型失败时保留检测框与人工复核入口，允许稍后重试。
- 提交前重试与提交后恢复区分处理，避免因重连多次新建同一图片记录；具体请求去重方式与队员一确认。

### 4. 问答、人工复核与记录

- 助手携带当前图片或批次上下文，支持文字追问；切换对象时清楚提示，避免串用旧记录。
- 显示引用依据、复检步骤、参考原因与待补信息。没有规则时显示需要人工判断。
- 人工复核至少能确认、修正类别、记录漏检和填写备注；框的新增或修正采用一致的原图坐标。复杂框编辑若影响首轮进度，与团队确认简化方式并保留“补充漏检”记录能力。
- 提交复核包含结果版本；冲突时提示刷新，不能悄悄覆盖新内容。
- 查询历史与批次统计，保存或分享后端报告。导出格式和下载方式在首次联调时确定。

### 5. 离线、连接和隐私提示

- 分清手机无网络、工位不可达、外网API不可达三种情况。
- 工位可达而外网中断时继续展示本地检测；托管服务不可达时说明待上传/待重试，不宣称手机离线已检测。
- 首轮若不实现可靠的持久待上传队列，保留待提交信息并明确需要用户重试，不显示已经入库。
- 设置中可以查看服务状态与版本，上传图片前提供清楚说明。公开演示画面不显示密钥与私人配置。

## 六、与其他两名队员的交接

从队员一接收：合成响应、服务连接方法、类别映射、框坐标、WebSocket事件与错误码。先用样例做界面，不等模型训完；接口差异当天记录并统一。

交给队员一：前端所需字段、重试和记录版本需求、坐标问题的可复现图片与设备信息。

从队员三接收：页面文案、报告模板、审核过的缺陷解释、演示脚本与测试用例；交给队员三真实App截图、安装步骤、实际功能清单和已知限制。

## 七、完成标准

- [ ] 新设备可按说明安装，能连接队员一提供的服务。
- [ ] 一张真实测试图片可完成上传、检测、问答、人工确认、历史与报告流程。
- [ ] 预览大小变化、多个框与图片方向变化后，标注仍贴合原图。
- [ ] 权限拒绝、无网络、API超时、空检出分别有明确页面反馈。
- [ ] 页面切换和断线后可恢复已提交记录，不重复创建与重复追加消息。
- [ ] AI草稿、原预测和人工确认状态清楚，不把未知结果显示成合格。
- [ ] 实录画面标明公开数据测试，未使用合成结果冒充实际调用。

## 八、遇到工期压力时的取舍

先保Android、选图、单图结果、文字问答、复核与报告；相机兼容性、批量交互、复杂框编辑、桌面、语音和复杂动画按进度处理。重要功能简化须在已知限制中说明，不让按钮存在但无实际作用。11月6日后优先修正状态、坐标和连接问题。
